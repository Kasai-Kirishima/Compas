КОМПАС Онлайн 2.5.3.4 — чистая сборка

ЗАПУСК
1. Распакуйте архив в отдельную папку.
2. Откройте index.html в актуальном Chrome, Edge или Firefox.
3. Выберите инструмент в редакторе для построения геометрии.
4. Сохраняйте чертеж в JSON через интерфейс программы.

ШАБЛОН ЛАБОРАТОРНОЙ РАБОТЫ №5
- Формат A4, книжная ориентация.
- Рабочее поле оставлено пустым: геометрия детали не включена.
- Верхняя архивная полоса: два смежных поля без продольного деления.
- Нижняя архивная полоса: пять смежных полей с продольным делением.
- Дополнительная верхняя графа 70×14 мм содержит название работы, повернутое на 180°.
- В основном написе название работы находится в верхней центральной ячейке; нижняя центральная ячейка оставлена пустой.
- Таблица изменений: четыре пустые строки и строка заголовков.
- Таблица подписей: шесть строк — Розроб., Перевір., Т.контр., пустая строка, Н.контр., Затв.
- В нижнем блоке подписей графы Зм. и Арк. объединены; верхняя таблица изменений сохраняет отдельные колонки.
- Масштаб — 1:1; литера и масса не заполнены.
