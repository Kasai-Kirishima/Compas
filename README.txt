# CAD Geometry Core 1.5.23

## 1.5.23 advanced 2D sketch operations

- Object snaps are now connected to the main editor: endpoints, segment midpoints, circle/arc/ellipse centres, circle quadrants and intersections. The analytic geometry kernel is used for line/circle/arc and circle/circle intersections; sampled paths are used only where the source is intrinsically freeform.
- Trim now works by clicking the section to remove between adjacent intersections on line segments, circles, arcs, rectangles, ellipses and closed polylines. Source objects are replaced by editable pieces in one undoable transaction.
- Added the **Arc (3 points)** tool: start, a point on the arc, and end. The solver selects the corresponding minor/major sweep and rejects degenerate collinear input.
- Regular polygons now include **Across flats** sizing. For a hexagon with 40 mm across flats, set the cursor at the apothem distance (20 mm from the centre to the midpoint of a side); the core API accepts the full across-flats measurement.
- Added planar-region recognition from independent and intersecting sketch curves. The graph splits intersections, walks bounded faces, and classifies nested loops as holes/islands.
- Added automatic region hatching for the detected faces. Hatch segments are clipped around inner holes; solid hatching uses even-odd fill. Original source curves remain unchanged.
- Existing circles, lines, arcs, polygons, circular/rectangular arrays, single-boundary hatch, and basic geometry primitives were already present and were not duplicated. 3D boss extrusion and through-all Boolean cuts are not included because this project remains a 2D editor and has no 3D solid kernel.

## 1.5.23 full project exchange (.kcad)

Use **Экспорт проекта** to download a `.kcad` file. It preserves the complete editable drawing: all geometry, open/closed cut contours, dimensions and individual arrow/label settings, text with multi-line content and frames, title-block/frame template and per-cell overrides, sheet and GOST/DSTU settings, layers/visibility, ruler and viewport options, and embedded image references. Use **Импорт проекта** to restore it; the application automatically creates a separate “— импорт” project in the local file library instead of overwriting the source. Legacy plain `.json` project files remain importable.

КОМПАС Онлайн 2.5.4.2 — учебный браузерный редактор чертежей

НОВЫЕ 2D-ИНСТРУМЕНТЫ 1.5.23
- Объектные привязки: конечные точки, середины, центры, квадранты и пересечения.
- Дуга по трём точкам: начало, точка на дуге, конец.
- Правильный многоугольник по граням: введите размер между параллельными сторонами; например, щелчок на 20 мм от центра задаёт шестигранник 40 мм между гранями.
- Trim удаляет выбранный сегмент между соседними пересечениями на отрезках, окружностях, дугах и замкнутых контурах.
- Автопоиск замкнутых областей по нескольким пересекающимся кривым и штриховка с пропуском внутренних отверстий.
- 3D-выдавливание и булевы 3D-вырезы пока не поддерживаются: текущая программа является 2D-редактором.

ЗАПУСК
1. Распакуйте архив в отдельную папку.
2. Откройте index.html в актуальном Chrome, Edge или Firefox.
3. Выберите формат/шаблон листа и создавайте чертёж.
4. Для полного переноса чертежа используйте «Экспорт проекта» (.kcad); импорт восстанавливает редактируемый документ как новый отдельный проект.

УПРАВЛЕНИЕ ОБЪЕКТАМИ
- Запретить перемещение выбранного объекта: выделите его и включите «Заблокировать объект» в панели свойств.
- Заблокировать все существующие объекты: нажмите «Заблокировать всё». Новые объекты, созданные после этой команды, автоматически не блокируются.
- «Разблокировать всё» снимает блокировку со всех объектов.
- Удаление и ластик не удаляют заблокированные объекты. Ластик удаляет целый объект/элемент, а не часть линии.
- Поворот выбранного объекта доступен через поле угла, ползунок и быстрые значения угла. Стрелки клавиатуры перемещают только незаблокированные выбранные объекты.

РАЗМЕРЫ ПО ЕСКД / ГОСТ
- Высота размерных чисел выбирается из ряда шрифта типа Б по ГОСТ 2.304: 1,8; 2,5; 3,5; 5; 7; 10; 14; 20 мм.
- Для новых размерных чисел базовая высота установлена 7 мм; можно выбрать любой стандартный размер из ряда 1,8; 2,5; 3,5; 5; 7; 10; 14; 20 мм. Настройка действует на новые размеры, а высоту существующих можно менять отдельно.
- По умолчанию размерное число сохраняет горизонтальную ориентацию при повороте размерной линии. Для наклонного/повёрнутого размера добавляется полка/ответвление, чтобы текст читался горизонтально. При необходимости можно выбрать ориентацию параллельно размерной линии.
- Положение числа можно изменить перетаскиванием бирюзовой ручки рядом с текстом или значениями смещения X/Y в свойствах размера. Полка/выноска следует за смещённым текстом.
- Для выносных ножек размера доступны одинаковые настройки зазора от контура и продолжения за размерную линию. Продолжение применяется одинаково к обеим ножкам.
- В свойствах выбранного размера можно временно скрыть или снова показать его числовое значение, не удаляя сам размер. По умолчанию значение показывается; перед выпуском чертежа проверьте, что все необходимые размерные числа включены.
- Режим стрелок «Авто» выносит стрелки наружу, когда между ними не помещаются наконечники и размерный текст; также доступны варианты «Внутри» и «Снаружи».
- В свойствах размера можно менять форму стрелок (закрашенный треугольник, открытая V, засечка, точка или без стрелок), задавать разные наконечники на первом и втором концах и менять их размер.
- Угол размерного числа настраивается отдельно от размерной линии: от −360° до +360°; «Сбросить до 0°» возвращает обычный угол. Эти настройки применяются также к нескольким выделенным размерам одновременно.

РЕДАКТИРОВАНИЕ ТЕКСТА
- Двойной щелчок по тексту открывает его редактирование.
- Двойной щелчок по пустой ячейке позволяет добавить надпись.
- Текстовые поля основной надписи можно менять через панель свойств; текстовые объекты и ячейки пользовательских таблиц редактируются непосредственно на листе.

ЛАСТИК И УГОЛ
- Выберите инструмент «Ластик» и щёлкните по объектам или проведите курсором по ним, чтобы удалить целые объекты. Заблокированные объекты защищены от стирания.
- Для поворота используйте поле угла, ползунок или быстрые углы. Блокировка объекта запрещает его перемещение и изменение через обычное выделение; сначала разблокируйте объект.

ПРИМЕЧАНИЕ
Это независимый учебный браузерный прототип, а не официальная версия КОМПАС-3D и не сертифицированная CAD-система. Формы листов и правила оформления приведены для учебного использования; проверяйте применимый стандарт и методичку преподавателя. Прототип не заменяет профессиональную проверку конструкторской документации.


КАТЕГОРИИ ИНСТРУМЕНТОВ
- Инструменты слева сгруппированы по вкладкам: Геометрия, Размеры, Обозначения, Редактирование, Точность, ЕСКД / ГОСТ, Подложка, Лист и слои. Вкладка «Все» показывает все разделы сразу.
- В категории «Редактирование» находятся копирование, сдвиг, поворот, зеркальное отображение, масштабирование, скругление, фаска, массивы, усечение, блокировка, группировка и выравнивание.
- В категории «Точность» собраны координатный ввод, сетка, привязки, ортогональное черчение, линейка и шаг угла.
- В категории «ЕСКД / ГОСТ» собраны профиль оформления, нормализация выбранных объектов, проверка требований и размеров задания.
- В категории «Лист и слои» находятся штриховка, шаблоны форматов и видимость слоёв.
- В свойствах выбранного размера флажок «Показывать числовое значение размера» позволяет скрыть только цифру/обозначение, оставив размерные линии и стрелки. Это вспомогательная возможность; для окончательного чертежа убедитесь, что размеры подписаны согласно заданию.

- Скрытие числового значения — вспомогательная возможность для компоновки/эскизов; в окончательной документации проверьте, что все требуемые размеры имеют числовые обозначения.

ПРЯМОЙ ПРОХОДНОЙ ВЫРЕЗ (1.5.21)
- В панели «Вырез и отверстия» выберите «Без нижней стенки» (две ровные параллельные боковые стенки, открытый внутренний конец) или «Без стенок» (удаляется только часть границы, новые боковые линии не создаются).
- Задайте ширину, нажмите левую кнопку мыши с любой стороны и под любым углом, протяните линию и отпустите в нужной глубине. Если начало жеста внутри конкретного профиля, а конец снаружи, алгоритм сам разворачивает направление только для этого профиля. Если начало жеста оказалось внутри конкретного профиля, а конец снаружи, направление для этого профиля автоматически разворачивается. Один проход обрабатывает все пересечённые видимые незаблокированные замкнутые профили.


1.5.21: repeated cuts preserve every earlier open end. The temporary closing segment used for Boolean reconstruction is tagged and removed again (including split pieces), so a previous no-bottom end never reappears as a visible wall during a later pass. The selected mode applies only to the new cut.

ПОВТОРНЫЕ ПРОХОДЫ (1.5.21)
- Повторный проход по открытому контуру, полученному предыдущим прямым вырезом, теперь заново строит боковые стенки в соответствии с текущим режимом. В режиме «Без нижней стенки» две стенки остаются прямыми и параллельными, нижний торец не рисуется. Режим «Без стенок» не добавляет боковые линии. Временное замыкание контура используется только при вычислении и не отображается. Обычные открытые отрезки по-прежнему получают простой разрыв без добавочных стенок.

1.5.21: временный отрезок между концами старого открытого выреза больше не записывается в итоговую геометрию. Предыдущие открытые участки сохраняются открытыми при втором, третьем и дальнейших проходах.

1.5.27: тонкая штрихпунктирная линия по ГОСТ 2.303-68 использует короткий штрих 5 мм и промежутки 3 мм; старые встроенные пресеты автоматически нормализуются при отображении.
