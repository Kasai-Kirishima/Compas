# Каталог рамок CAD Geometry Core 1.5.57

В активной библиотеке семь различных вариантов:

| Файл | Название | Формат |
|---|---|---|
| `Lab4-A3-portrait.svg` | Лабораторная работа №4, пользовательский образец | A3, книжный |
| `Lab8-A3-landscape.svg` | Лабораторная работа №8, синяя рамка «Корпус / Вариант 8 / ШЦМГУ» | A3, альбомный |
| `Lab5-A4-portrait.svg` | Лабораторная работа №5, мобильный образец KOMPAS | A4, книжный |
| `Lab5-GOST-A3-landscape.svg` | ЛР №5, форма 1 ГОСТ/ЕСКД | A3, альбомный |
| `Technical-GOST-A3-landscape.svg` | Технический чертёж, форма 1 ГОСТ/ЕСКД | A3, альбомный |
| `Lab5-GOST-A3-portrait.svg` | ЛР №5, форма 1 ГОСТ/ЕСКД | A3, книжный |
| `Technical-GOST-A3-portrait.svg` | Технический чертёж, форма 1 ГОСТ/ЕСКД | A3, книжный |

Для каждого SVG в комплекте есть PNG-предпросмотр с суффиксом `-preview`.

Первые три шаблона восстановлены по изображениям пользователя. Четыре последних — ранее созданные варианты формы 1 в двух ориентациях. Ранний экспорт `CAD-A3-Technical-Template.svg` имеет ту же геометрию, что и текущий Lab 8, поэтому не дублируется отдельным пунктом. Скрытые legacy ID в коде сохранены только для открытия старых `.kcad`.


Размер листа можно менять после выбора шаблона: А4 (210×297 мм), А3 (297×420 мм), А2 (420×594 мм), книжная или альбомная ориентация. Шаблон задаёт только рекомендуемый начальный формат. SVG/PDF и печать используют фактически выбранные размеры листа.

## Исправление ЛР8 (1.5.57)

- Увеличены надписи в рамке, шапке и основной надписи.
- Перестроена нижняя левая таблица: 13 мм под наименование должности, 27 мм под ФИО, далее поля подписи и даты.

- Формат листа сохранён: А3 альбомный, 420 × 297 мм.
