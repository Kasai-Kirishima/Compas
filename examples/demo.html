CAD Geometry Core 1.1 — интерактивный Trim

Небольшой пример подключения геометрического ядра к HTML5 Canvas

Режим: Trim — щёлкните по участку между пересечениями
Как проверить: щёлкните по горизонтальному отрезку между вертикальными резаками, затем по верхней или нижней половине окружности. Участок между соседними пересечениями будет удалён. Заблокированная геометрия может служить режущей границей, но не выбирается для изменения.
Координаты ядра мировые, в миллиметрах; пример применяет преобразование Canvas с осью Y вверх.
