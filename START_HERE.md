# Начало работы — CAD Geometry Core 1.5.58, восстановленная сборка

## Публикация на GitHub Pages (для работы через GitHub)

1. Распакуй ZIP. Не загружай в репозиторий один ZIP вместо файлов сайта.
2. Загрузи в корень репозитория все файлы и папки из распакованного проекта. В корне должны находиться `index.html`, `styles.css`, `js/` и `src/`.
3. Открой GitHub → репозиторий → **Settings → Pages**.
4. Выбери **Deploy from a branch** → ветка `main` → папка `/(root)` → **Save**.
5. Перейди по адресу сайта, который покажет GitHub Pages.

Если GitHub показывает README вместо редактора, проверь, что `index.html` лежит прямо в корне репозитория, а не внутри вложенной папки.

## Локальный запуск на Windows

1. Распакуйте ZIP целиком в отдельную папку.
2. Дважды щёлкните `start.bat`.
3. Редактор откроется в браузере по адресу `http://127.0.0.1:8000/`.
4. Не закрывайте окно сервера, пока работает редактор.

Альтернатива: откройте терминал в папке проекта, выполните `npm start` и перейдите на `http://127.0.0.1:8000/`. Нужен Node.js 18+. Прямое открытие `index.html` через `file://` не подходит из-за ограничений браузера на ES-модули.

Формат и ориентацию листа можно изменить через список «Формат аркуша». Размер бумаги влияет на предпросмотр и печать.

## Основные инструменты

- **Геометрия:** выбор, ластик, точка, отрезок, стрелка 1, линейка, свободная линия, вспомогательная прямая, луч, осевая, ломаная, прямоугольник, скруглённый прямоугольник, окружность, дуга, эллипс, многоугольник.
- **Размеры:** линейный, горизонтальный, вертикальный, радиус, диаметр, простой авторазмер и измерение. Для обычного линейного размера укажите две точки, затем положение размерной линии.
- **Обозначения:** текст, выноска, центр, штриховка выбранного замкнутого контура, шероховатость, допуск, сварка, таблица.
- **Черчение:** для отрезка, стрелки и сплайна можно сначала поставить первую точку, затем нажать на конечную точку и тянуть её: показывается живой предпросмотр с маркерами концов. Также доступны обычное построение двумя щелчками и протягивание ЛКМ. Сплайн можно строить последовательно по точкам; Enter или двойной щелчок завершает его. Высота новых и импортированных размерных чисел по умолчанию — 2,5 мм.
- **Навигация по рабочему пространству:** перемещается весь белый лист вместе с рамкой и геометрией, а не содержимое внутри зафиксированного листа. На мыши зажми среднюю кнопку (нажатие на колесико) или правую кнопку и двигай курсор. На ноутбуке — Space + перетаскивание ЛКМ либо кнопка «Ладонь» + ЛКМ. Двухпальцевый плавный свайп на тачпаде перемещает весь лист; pinch/сведение пальцев или Ctrl+колесико приближает и отдаляет. Обычное колесико мыши — масштаб вида вокруг курсора. Кнопки «−»/«+» меняют масштаб вида, не геометрию рамки.
- **Редактирование:** выбрать объект щелчком или в дереве документа — откроется вкладка «Свойства». Можно менять радиус/диаметр и центр окружности, координаты/длину/угол отрезка, вершины ломаной/сплайна, ширину/высоту прямоугольника, полуоси эллипса, параметры дуги, размерные точки и текст. Delete удаляет, Ctrl+Z отменяет, Ctrl+Y повторяет. Отмена/повтор не меняют текущий масштаб и положение листа.
- **Обычный текст:** после выделения надписи перетаскивайте голубой квадрат для свободного перемещения или ромб для перемещения вдоль направления текста. Белая ручка меняет высоту шрифта, оранжевая — поворот. В свойствах доступны ползунки и крупные кнопки быстрых шагов для размера и угла.
- **Поворот:** выделите объект. Используйте угол в свойствах и кнопку «Повернуть», быстрые кнопки ±15/45/90° или потяните круглую янтарную ручку над рамкой выделения. Shift при вращении мышью фиксирует угол с шагом 15°. Повернутый прямоугольник становится многоугольником; это позволяет сохранить точную геометрию под произвольным углом. У окружности вращение вокруг собственного центра визуально незаметно.
- **Точки редактирования:** у отрезков и ломаных видимые маркеры маленькие, чтобы не закрывать контуры; область захвата курсора больше и прозрачная.

## Сохранение и обмен

- `.kcad` — редактируемый JSON-проект с геометрией; импортируются также файлы Kompas Online v14, включая документ `kind: kompas-online-project`. Импорт сначала добавляет документ в список файлов, не открывая и не накладывая его на активный чертёж. Чтобы открыть его, нажмите «Відкрити» в карточке файла. Сохраняются формат, поля штампа, геометрия, розміри, написи та властивості об’єктів.
- Встроенная библиотека хранит проекты локально в браузере (localStorage) на этом компьютере и в этом профиле браузера.
- SVG — векторный вывод; PNG/JPEG/WebP — растровый вывод; DXF — базовые линии, окружности, тексты и полилинии; печать — через браузер в PDF.
- Нативные CDW/DWG браузерный редактор не создаёт.

## Чего пока нет в восстановленной сборке

Проходные вырезы из замкнутых профилей (в том числе из отверстия наружу), произвольные Offset/Trim/Fillet/Chamfer, редактирование граней и автоматическая штриховка вложенных контуров пока не восстановлены. Удаление участка на открытом отрезке/ломаной и простое разделение путей/многоугольников доступны. Старое описание этих кнопок в интерфейсе относится к отсутствовавшей реализации. Ограниченные команды показывают предупреждение, а не изменяют чертёж молча.

Полный список: `docs/RESTORATION-NOTES.md`.


## Важно о соответствии стандартам

Чорний шаблон ЛР №8 відтворює компоновку наданого зразка (в оригінальному зображенні лінії були сині): А3 альбомный 420 × 297 мм, отступы рамки 20/5/5/5 мм и поле штампа 185 × 55 мм с сеткой формы 1. Боковые ячейки и надписи принадлежат образцу учебного заведения; их нельзя считать обязательной частью ГОСТ. По реестру ДСТУ EN ISO 5457:2022 действует для форматов чертежей, а ДСТУ ГОСТ 2.104:2006 имеет ограниченную сферу действия. Это учебная реконструкция, поэтому перед сдачей чертежа сверь заполнение и оформление с требованиями преподавателя/учебного заведения.

## Импорт вашего файла Kompas Online

Нажмите **Імпортувати файл** на верхней панели и выберите файл с расширением `.kcad`. Он появится в списке файлов; затем отдельно нажмите **Відкрити**. Текущий чертёж до этого не изменяется. Для проверки в папке `examples` находится исходный файл `Лаб4-КушвидО-Актуальный-файл-Kompas.kcad`. Редактор открывает его как отдельный проект; исходный файл остаётся без изменений. Импортируются поддерживаемые объекты, их координаты, размеры, текст и данные штампа.

Восстановленная рамка Kompas для этого проекта чёрная. Остальные рамки библиотеки также отображаются чёрными.


### Референс (изображение-подложка)

При добавлении PNG/JPG/WEBP/BMP изображение размещается с сохранением исходного соотношения сторон. Выдели референс: в свойствах доступны ширина и высота (при включённом флажке второе значение пересчитывается автоматически), кнопки увеличения ×1,25 и ×2, уменьшения ×0,8, поворот и команда «Вписать в лист». Можно перетащить нижний правый маркер рамки референса; с включёнными пропорциями размер меняется без искажения изображения. Если пропорции намеренно нужно растянуть, выключи флажок.


### Референсы
Откройте отдельную вкладку **«Референсы»** слева. Там находится список картинок с миниатюрами и отдельные кнопки видимости/блокировки. Выберите картинку, чтобы открыть крупный предпросмотр и управлять прозрачностью, масштабом, вписыванием, центровкой, блокировкой и удалением. Новые референсы отображаются с непрозрачностью 88%.

### Стрелка
Інструмент «Стрелка 1» створює пропорційний трикутний наконечник. Його довжина вимірюється вздовж осі стрілки, а ширина — перпендикулярно; наконечник більше не сплющується при горизонтальному або діагональному напрямку.

### Вкладка «Референсы»
Окрема вкладка зліва показує список завантажених зображень, мініатюри й обраний референс. У ній доступні показ/приховування, блокування, прозорість, збільшення/зменшення, вписування в лист, центрування та видалення.


### Стрелки и размерные числа
Выдели объект «Стрелка» или «Гнутая стрелка» и открой вкладку «Свойства»: поле «Размер наконечника, мм» регулирует наконечник независимо от толщины линии. Начальное значение — 3,2 мм; диапазон — 0,5–20 мм.

Чтобы увеличить только цифру уже созданного размера, выдели размер и поменяй «Размер цифры этого размера, мм» числом или ползунком. Стрелки размера и выносные линии при этом не изменяются.


### Поворот и увеличение объекта

1. Выберите объект инструментом «Выбор».
2. Для точного поворота откройте «Свойства» → «Поворот», укажите итоговый угол и нажмите «Повернуть». Либо тяните янтарную ручку над объектом.
3. Для изменения масштаба используйте «Свойства» → «Масштаб объекта»: введите коэффициент и нажмите «Применить масштаб».
4. Для окружности, эллипса и прямоугольника можно тянуть угловые маркеры рамки выделения.
5. Чтобы отменить операцию, используйте Ctrl+Z.


## Исправление толщины букв при PDF-печати (restored.24)

В системном окне печати буквы шаблона и основной надписи остаются обычной толщины. Для текста отключена чёрная обводка, которая раньше применялась к линиям рамки и шаблона и случайно утолщала символы. Чёрная заливка букв и печать геометрических линий сохранены.
