# Начало работы — CAD Geometry Core 1.5.56

## Библиотека рамок: 7 вариантов

**Пользовательские образцы:**

1. **Лабораторная работа №4** — А3 книжный, по вертикальному образцу.
2. **Лабораторная работа №8** — А3 альбомный, синяя рамка со штампом «Корпус / Вариант 8 / ШЦМГУ».
3. **Лабораторная работа №5** — А4 книжный, по мобильному скриншоту KOMPAS.

**Созданные варианты ГОСТ / ЕСКД:**

4. ЛР №5 — форма 1, А3 альбомный.
5. Технический чертёж — форма 1, А3 альбомный.
6. ЛР №5 — форма 1, А3 книжный.
7. Технический чертёж — форма 1, А3 книжный.

Каждый вариант доступен в боковой галерее, выпадающем списке «Выбрать шаблон» и в окне создания нового документа. При выборе шаблона устанавливается рекомендуемый стартовый формат, но он не блокируется: после этого можно вручную переключать А4 (210×297 мм), А3 (297×420 мм) и А2 (420×594 мм), книжную или альбомную ориентацию. Выбранные размеры используются в листе, сохранённом проекте, SVG и печати/PDF. Для пользовательских образцов ЛР4 и ЛР5 в поле разработчика указано строго `Кушвид О.`.

Ранний файл `CAD-A3-Technical-Template.svg` совпадает по геометрии с синей рамкой ЛР8 и не добавлен как дубликат. Старые ID остаются скрытыми и используются только при открытии прежних `.kcad`.

## Запуск

1. Распакуйте архив в отдельную папку.
2. Откройте `index.html` в Chrome или Edge.
3. Выберите нужную рамку в левой галерее или в списке «Оформление листа».
4. Для нового чертежа нажмите «Создать» и выберите нужный вариант. Затем при необходимости измените размер и ориентацию листа в соответствующих списках и проверьте предпросмотр.
5. Сохраняйте рабочие файлы в `.kcad`; для печати используйте PDF/печать в масштабе 100% / Actual size.

## Инструменты и вкладки

Панель разбита на категории: «Геометрия», «Размеры», «Обозначения», «Редактирование», «Привязки», «ЕСКД / ГОСТ», «Подложка», «Лист» и «Все». Полный состав вкладок описан в `docs/TOOL-TABS.md`.

**Стрелка 1** находится рядом с «Отрезком». Выбери инструмент, щёлкни пустое начало, затем конец со стрелкой. Она строится в два щелчка и работает как обычный отрезок: поддерживает Shift, Ortho, OSNAP, линейку, выделение, перемещение и редактирование.

XLINE/RAY, окружности по радиусу/диаметру, OSNAP, Ortho (F8), Offset, Trim, Mirror, Fillet, слои, типы линий, размеры, центровые обозначения и единая штриховка остаются доступны. Для вырезов выбери направление «Снаружи внутрь» или «Изнутри наружу». Во втором случае сначала выдели внутренний замкнутый контур отверстия/кармана, затем щёлкни по его границе или протяни прямой проход из пустоты наружу.

Для проверки проекта (Node.js 18+) выполните `npm test`.


For **Стрелка 1**, change **Толщина линии** in Object Properties: the filled arrowhead scales proportionally with it. The default pair is 0.50 mm / 4.725 mm rendered head length; the triangle is also wider for visibility.

### Исправление выреза изнутри наружу — 1.5.56
Теперь предварительное выделение не обязательно: начни жест внутри отверстия/паза или внутри внешнего контура детали. Вложенные контуры распознаются автоматически; для одиночного внешнего контура строится выходной паз внутрь материала от края к точке начала.

**Внутренний проходной вырез:** выбери «Изнутри наружу» и протяни линию из отверстия/кармана через стенку за внешний край детали. Контуры могут быть собраны из отдельных соединённых отрезков или дуг.
