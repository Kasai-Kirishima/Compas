# Начало работы — CAD Geometry Core 1.5.58, восстановленная сборка

## Запуск на Windows

1. Распакуйте ZIP целиком в отдельную папку.
2. Дважды щёлкните `start.bat`.
3. Редактор откроется в браузере по адресу `http://127.0.0.1:8000/`.
4. Не закрывайте окно сервера, пока работает редактор.

Альтернатива: откройте терминал в папке проекта, выполните `npm start` и перейдите на `http://127.0.0.1:8000/`. Нужен Node.js 18+. Прямое открытие `index.html` через `file://` не подходит из-за ограничений браузера на ES-модули.

Пользовательские образцы ЛР4 и ЛР5 реконструированы по описанию из исходных README: исходных SVG/PDF шаблонов в ZIP не было. ЛР8 реконструирована по видимому образцу и changelog; её геометрию/типографику нужно сверять с заданием вручную. Все рамки — учебные, не сертифицированные официальные формы.

Формат и ориентацию листа можно изменить через список «Формат аркуша». Размер бумаги влияет на предпросмотр и печать.

## Основные инструменты

- **Геометрия:** выбор, ластик, точка, отрезок, стрелка 1, линейка, свободная линия, вспомогательная прямая, луч, осевая, ломаная, прямоугольник, скруглённый прямоугольник, окружность, дуга, эллипс, многоугольник.
- **Размеры:** линейный, горизонтальный, вертикальный, радиус, диаметр, простой авторазмер и измерение. Для обычного линейного размера укажите две точки, затем положение размерной линии.
- **Обозначения:** текст, выноска, центр, штриховка выбранного замкнутого контура, шероховатость, допуск, сварка, таблица.
- **Редактирование:** выбрать объект щелчком; Shift — добавить к выделению; перетаскивание — перемещение. Delete удаляет, Ctrl+Z отменяет, Ctrl+Y повторяет. Через панель доступны свойства, дублирование, вращение, зеркало, масштаб, массивы и выравнивание.
- **Привязки:** колесо — масштаб относительно курсора; правая кнопка мыши + движение — панорамирование; F8 — Ortho; Shift фиксирует угол с заданным шагом.

## Сохранение и обмен

- `.kcad` — редактируемый JSON-проект с геометрией, размерами, рамкой, полями штампа и настройками.
- Встроенная библиотека хранит проекты локально в браузере (localStorage) на этом компьютере и в этом профиле браузера.
- SVG — векторный вывод; PNG/JPEG/WebP — растровый вывод; DXF — базовые линии, окружности, тексты и полилинии; печать — через браузер в PDF.
- Нативные CDW/DWG браузерный редактор не создаёт.

## Чего пока нет в восстановленной сборке

Проходные вырезы из замкнутых профилей (в том числе из отверстия наружу), произвольные Offset/Trim/Fillet/Chamfer, редактирование граней и автоматическая штриховка вложенных контуров пока не восстановлены. Удаление участка на открытом отрезке/ломаной и простое разделение путей/многоугольников доступны. Старое описание этих кнопок в интерфейсе относится к отсутствовавшей реализации. Ограниченные команды показывают предупреждение, а не изменяют чертёж молча.

Полный список: `docs/RESTORATION-NOTES.md`.
