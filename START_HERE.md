# Начало работы — CAD Geometry Core 1.5.38

1. Распакуйте архив в отдельную папку.
2. Откройте `index.html` в Chrome или Edge.
3. Для XLINE/RAY выберите инструмент в группе геометрии и укажите две точки направления.
4. Для окружности выберите режим «Радиус» или «Диаметр» в настройках геометрии.
5. Включайте необходимые режимы OSNAP отдельно в панели привязок. Касательная привязка строится относительно предыдущей опорной точки.
6. F8 включает/выключает Ortho.
7. Чтобы менять тип линии выбранных объектов, используйте поле роли линии в свойствах; видимость основной, тонкой и осевой линий настраивается отдельно.
8. Для Offset выберите объекты и нажмите «Смещение». Для Fillet выберите два пересекающихся отрезка или прямоугольник.
9. Для центровых обозначений выберите окружности и нажмите «Обозначить центры».

## Важно

Fillet произвольной пары окружностей/дуг пока не поддерживается. Список реально доступных операций и их ограничений находится в `README.md`.

Для проверки проекта выполните `npm test` (Node.js 18+).
