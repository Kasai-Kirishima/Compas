# Начать работу — CAD Geometry Core 1.6.0 / Лаба 8

## Запуск в Windows

1. Полностью распакуйте архив в обычную папку (не запускайте программу прямо внутри ZIP).
2. Дважды щёлкните `Открыть_программу.bat` или откройте `index.html` через Chrome / Edge.
3. Должен открыться лист A3 в альбомной ориентации с рамкой «Лаба 8».
4. Формат переключается в правой панели: A3 (420 × 297 мм) или A4 (297 × 210 мм). Рамка подставляется автоматически.

Node.js и установка npm-пакетов для обычного запуска не нужны. Не удаляйте папки `js`, `templates`, `assets` и `src`.

## Первый чертёж

1. Выберите инструмент слева: отрезок, прямоугольник, окружность, эллипс, ломаная или текст.
2. Для линии и фигур зажмите левую кнопку мыши на листе, протяните и отпустите. Для ломаной ставьте точки; Enter завершает её.
3. Чтобы изменить текст, выберите инструмент «Добавить текст» и щёлкните по существующей надписи.
4. Выделяйте и перемещайте объекты инструментом «Выбор». Delete удаляет выбранное.
5. Ctrl+Z — отменить, Ctrl+Y — повторить, F8 — ортогональный режим.

## Сохранение и экспорт

- Ctrl+S или «Экспорт проекта» скачивает редактируемый файл `.kcad`.
- «Импорт проекта» открывает сохранённый `.kcad`.
- Также доступны SVG, PNG, DXF и CSV.
- «Печать / PDF»: выберите бумагу A3/A4, масштаб 100% / Actual size, поля 0 мм и отключите автоматическое вписывание.
- Библиотека и автосохранение используют хранилище браузера. Если браузер запретил его для локального файла, список работает до закрытия вкладки; скачивайте `.kcad` для постоянного хранения.

## Проверка кода

При установленном Node.js 18+ откройте терминал в этой папке и выполните `npm test`. Для альтернативного запуска через локальный сервер используйте `npm start`, затем перейдите на `http://localhost:8000`.

## Важно

Это восстановленная базовая версия, а не оригинальный отсутствующий CAD-движок. Реализованы базовые 2D-инструменты, A3/A4, шаблон «Лаба 8», текст/размеры, редактирование, отмена/повтор и базовый импорт/экспорт. Не реализованы булевы вырезы, сплайны/дуги, штриховка, растровые подложки, расширенные CAD-операции и нативные CDW/DWG. Недоступные элементы прежнего интерфейса отключены.
