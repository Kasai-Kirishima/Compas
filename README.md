# CAD Geometry Core 1.5.40

Обновление инструментов построения для редактора CAD Geometry Core с сохранением существующих функций и добавлением третьего шаблона А3 книжной ориентации.

## Что добавлено в 1.5.39

- **Дополнительный шаблон «Лабораторная работа №4 — по образцу»:** подключена сохранённая отрисовка макета с верхним полем, боковыми архивными графами и увеличенной нижней основной надписью. Он доступен отдельно от двух прежних вариантов и автоматически использует А3 книжный формат.
- При переключении шаблонов сохраняются геометрия и пользовательские надписи; у нового варианта установлены образцовые значения для лабораторной работы №4.
- Предыдущие варианты «Лабораторная работа №5» и «Технический чертёж» не удалены и не заменены.

## Что добавлено в 1.5.38

- **Бесконечная прямая (XLINE) и луч (RAY):** построение по двум точкам, отображение в пределах листа, сохранение/чтение в DXF как XLINE и RAY.
- **Окружность по радиусу или диаметру:** режим задаётся в панели геометрии.
- **OSNAP:** независимое включение/выключение конечных точек, середин, центров, пересечений, квадрантов и касательных точек. При наведении показывается маркер привязки. Для касательной нужна первая опорная точка.
- **Ortho:** существующий режим F8 ограничивает направление ортогональными осями.
- **Слои/видимость:** отдельная видимость основной, тонкой и осевой линий; выбор роли линии и толщины для новых примитивов и выбранных объектов.
- **Смещение (Offset):** отрезков, окружностей, дуг, прямоугольников и ломаных/сплайнов (сплайны смещаются как полилинии по их управляющим точкам).
- **Сопряжение (Fillet):** скругление прямоугольника и сопряжение двух выбранных отрезков с подрезкой их концов, если радиус помещается на обоих отрезках.
- **Центровые обозначения:** пакетное добавление маркеров центра для выбранных окружностей.
- **Trim и Mirror:** сохранены существующие инструменты усечения и зеркального отражения.
- **Размеры и оформление:** сохранены линейные, диаметральные, радиальные и угловые размеры, существующие слои и A3-шаблоны.

## Известные ограничения

- Fillet для произвольной пары «окружность–окружность», «дуга–окружность» и «дуга–дуга» пока не реализован; сопряжение работает для двух отрезков и скругления прямоугольника.
- Offset кривой сплайна строится по её сохранённым точкам и может быть менее гладким, чем исходный сплайн.
- Trim работает по существующим поддерживаемым типам геометрии, но не выполняет автоматическое глобальное объединение совпадающих сегментов.
- В DXF XLINE/RAY представлены соответствующими сущностями; проверяйте совместимость с целевой CAD-программой при импорте.

## Запуск

Откройте `index.html` в современном браузере. Для тестирования установите Node.js 18+ и выполните:

```bash
npm test
```

Никаких внешних npm-зависимостей для запуска редактора нет.
