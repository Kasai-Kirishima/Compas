# CAD Geometry Core 1.5.58-restored.20 — восстановленная сборка (.10)

Браузерный 2D-CAD для учебных технических чертежей в миллиметрах. В исходном ZIP остались интерфейс (`index.html`, `styles.css`) и документация, но отсутствовали все программные модули и тесты. Эта сборка восстанавливает рабочее ядро по сохранившимся интерфейсу, README, START_HERE и CHANGELOG.

## Публикация через GitHub Pages

1. Распакуйте архив на компьютере. В репозиторий нужно загрузить **содержимое** папки проекта, а не один ZIP-файл.
2. В корне репозитория должны лежать `index.html`, `styles.css`, папки `js/` и `src/`.
3. На GitHub откройте **Settings → Pages**. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните.
4. Откройте адрес Pages, показанный GitHub. Не переименовывайте и не переносите отдельно папки `js/` и `src/`: приложение загружает ES-модули по относительным путям.

Для локального запуска на Windows:

**Windows:** распакуйте папку целиком и дважды щёлкните `start.bat`. Скрипт поднимает локальный сервер и открывает редактор в браузере. Для этого нужен Node.js 18+ или Python 3.

**Вручную:** из папки проекта выполните:

```bash
npm start
```

Затем откройте `http://127.0.0.1:8000/`. Не запускайте `index.html` двойным щелчком: браузеры блокируют ES-модули при загрузке через `file://`.


## Навигация мышью

- Панорамирование двигает ВЕСЬ лист (белую бумагу вместе с рамкой и чертежом) по свободному серому рабочему пространству. Средняя кнопка/нажатие на колесико + движение или правая кнопка + движение панорамируют лист. На ноутбуке используйте Space + перетаскивание ЛКМ или включите кнопку «Ладонь» и тяните лист ЛКМ. Двухпальцевое плавное движение по тачпаду перемещает лист; горизонтальное движение тоже панорамирует. Колесико обычной мыши приближает/отдаляет ВИД относительно курсора; Ctrl+колесико и жест pinch на тачпаде также масштабируют. Кнопки «−» и «+» меняют только масштаб камеры. Ни один из этих жестов не изменяет рамку или геометрию внутри бумаги. Shift+колесо сдвигает по горизонтали, Alt+колесо — по вертикали.

## Восстановленные функции

- Листы A4, A3, A2, A1, A0 и ряд удлинённых форматов; книжная и альбомная ориентация.
- Четырнадцать пресетов рамок: по умолчанию открывается чёрный образец ЛР №8 «Корпус / Вариант 8 / ШЦМГУ» на А3 альбомном 420×297 мм; доступны учебные ЛР4/ЛР5 и варианты формы 1 на листах А4/А3/А2. Рамка ЛР №8 измерена по растру образца на листе 420×297 мм: тонкий внешний контур, внутренняя рамка x=4,5 мм / y=4 мм с левой вертикалью рабочей зоны x=16,3 мм, левая боковая полоса с делением на секции и основной штамп 185×55 мм в нижнем правом углу; в строках разработчика/проверяющего стоят «Кушвид О.» и «Базиль Б.». Все линии шаблонов и рамок используют чёрный цвет `#000000`; микроподписи левой полосы ЛР №8 восстановлены украинскими аналогами, так как в исходном растре они неразборчивы. Для шаблона `lab8-a3-landscape-template` ориентация фиксирована: А3 альбомный 420×297 мм.
- Базовая геометрия: отрезки, стрелка с одним заполненным наконечником, окружности, прямоугольники, скруглённые прямоугольники, эллипсы, многоугольники, ломаные, дуги, свободные линии.
- Надписи, выноски, простые линейные/горизонтальные/вертикальные/радиальные/диаметральные размеры, центровые метки, осевые и вспомогательные линии, линейка, таблица.
- Выбор, множественный выбор, перемещение, удаление, дублирование, вращение, зеркальное отражение, масштабирование, массивы, выравнивание, свойства объектов.
- Сетка, привязка к сетке, базовые OSNAP к концам/серединам/центрам/квадрантам, Ortho и Shift-фиксация угла. Двухточечные инструменты работают как щелчками по двум точкам, так и протягиванием ЛКМ. После первой точки можно нажать на следующую и тянуть её: отрезок, стрелка и сплайн показывают живой предпросмотр с маркерами концов до отпускания кнопки. Высота новых и импортированных размерных чисел по умолчанию — 2,5 мм. Ломаная и сплайн также строятся последовательными щелчками.
- Локальное автосохранение, список файлов, `.kcad` (JSON-проект), экспорт SVG/PNG/JPEG/WebP и базовый DXF-импорт/экспорт. Импорт `.kcad`/`.json` сначала добавляет документ в список файлов; активный чертёж не заменяется и не накладывается. Открытие документа выполняется отдельной кнопкой «Відкрити» в списке.
- Печать через браузер / сохранение в PDF.

## Важные ограничения

Это восстановление, а не побитное возвращение исходного CAD-ядра: исходные `src/`, `js/`, `tests/`, `templates/` и `docs/` из архива отсутствовали. Сложные операции, описанные в старом README/CHANGELOG, не все восстановлены:

- проходные вырезы по замкнутым профилям «снаружи внутрь» / «изнутри наружу», булевы операции, режимы стенок и вырезание вложенных отверстий;
- произвольные Offset, Trim, Fillet, Chamfer, разделение замкнутых контуров и редактирование граней;
- автоматическое обнаружение нескольких вложенных областей для штриховки;
- полный DXF/DWG/CDW, CSV/HPGL/PLT, сложные DXF/SVG-сущности;
- параметрические зависимости и 3D-моделирование.

Эти пункты не маскируются: ограниченные кнопки сообщают об этом в строке состояния. DXF поддерживает базовые сущности, но экспорт нужно проверить в целевом CAD-приложении. Проверка ЕСКД — только учебный предварительный контроль, не официальный сертификат соответствия.

Точные ограничения и состав проверок: [`docs/RESTORATION-NOTES.md`](docs/RESTORATION-NOTES.md). Справка по категориям инструментов: [`docs/TOOL-TABS.md`](docs/TOOL-TABS.md).

Дополнительно выполнена браузерная проверка Chromium: live-preview для отрезка/стрелки/spline, импорт в библиотеку без наложения, повторное открытие, чёрные линии рамки и отдельный А3 альбомный шаблон. Для исходного `.kcad` проверен цикл экспорта/импорта всех 32 объектов, 5 размеров и текстовых полей.

Требуется Node.js 18+:

```bash
npm test
```

Тесты проверяют синтаксис модулей, основные геометрические функции, undo/redo, чтение/запись проекта и каталог шаблонов.


## Статус стандартов для шаблона

Образец ЛР №8 реконструирован по предоставленному изображению в альбомном А3 (420 × 297 мм): тонкий внешний контур, рабочая рамка с измеренными отступами 4,5 мм слева / 4 мм сверху (правый/нижний отступы 6,5/8 мм), дополнительная левая вертикаль рабочей зоны и нижний правый штамп 185 × 55 мм. Сетка штампа следует структуре формы 1; чёрные боковые поля и их подписи — индивидуальная часть образца, а не обязательный реквизит ГОСТ. В Украине ДСТУ EN ISO 5457:2022 указан как действующий стандарт форматов чертежных листов. ДСТУ ГОСТ 2.104:2006 в реестре отмечен как действующий с 01.03.2026 по 25.11.2027 с ограниченной сферой применения. Поэтому шаблон следует считать учебной реконструкцией по образцу, а не официальным сертификатом соответствия для любой области применения.

## Импорт проекта Kompas Online (.kcad)

В `examples/Лаб4-КушвидО-Актуальный-файл-Kompas.kcad` приложен исходный файл, который был предоставлен для настройки рамки. Для импорта в редакторе нажмите **Импорт проекта** и выберите `.kcad`. Импорт сначала добавляет отдельный файл в библиотеку. После этого нажмите **Відкрити** в его карточке. Это заменяет активный документ целиком, не объединяя его геометрию с текущей. Для предоставленного файла проверено 32 объекта, в том числе 5 размеров, текст и поля основной надписи; собственный экспорт `.kcad` и повторный импорт сохраняют полный набор полей и объектов. Для этого файла распознаётся А4, книжная ориентация, и применяется восстановленный чёрный шаблон `kompas-lab5-a4-template`. Исходный файл не перезаписывается.

Поддерживаются типы объектов Kompas Online, присутствующие в предоставленном файле: отрезки, вспомогательные линии, полилинии/контуры, эллипсы, размеры и текст. Другие специфические сущности Kompas могут быть пропущены. После импорта проверьте размеры и подписи перед печатью или сдачей. Высота импортированных размерных чисел установлена компактной (2,5 мм), при этом значения размеров, координаты, выносные линии, текст и дополнительные свойства объектов остаются в проекте.

**Цвет рамок:** все рамки, вспомогательные поля и основная надпись в каталоге шаблонов строятся чёрным цветом. Цветовые маркеры в интерфейсе обозначают слои/инструменты и не меняют цвет печатной рамки.


### restored.11 — title block readability correction
- Author and checker names are now placed in the signature column; the `№ докум.` cell is left clear.
- Enlarged the document designation and numerical values (scale, sheet number/count, literature/mass fields) in the A3 Lab 8 title block.


### Reference manager
Open the **Референсы** tab in the left panel to add images, view thumbnails, select a reference, toggle visibility or locking, adjust opacity, scale it, fit it to the sheet, center it, or remove it. New references use 88% opacity; the image is rendered with a single opacity multiplier so it remains readable.

### Arrow geometry
The standalone arrow uses a proportional filled triangular head. Its length is measured along the shaft and its half-width perpendicular to the shaft; the head angle is no longer calculated by mixing millimetres and radians.


## Workspace tabs and object editing (restored.18)

The left tool area is separated into Tools, Document, Properties, References and Settings. Tool categories and settings subtabs keep controls from appearing in one long list. Select an existing object to edit its geometry from the Properties panel (for example, enter a new circle radius/diameter or line length/angle). Rotate with the angle input, quick-angle buttons, slider or the circular handle above the selection; Shift snaps mouse rotation to 15°. Undo/redo retain the current viewport. Curved arrows are smooth splines with a compact triangular tip. Selection grips are visually small with larger transparent hit areas.


## Arrowhead and dimension text sizing (restored.19)

- Straight and curved arrow objects use a smaller 3.2 mm default arrowhead. Select an arrow and change **Размер наконечника** (0.5–20 mm) in object properties to enlarge or reduce it independently of line thickness.
- Existing dimension labels can be resized separately from their arrowheads using the numeric **Размер цифры этого размера** field or its slider (0.5–30 mm).
- The default height for newly created dimension numbers is independently configurable in Drawing Settings.
- Arrowhead size, dimension number height, and dimension arrow size are stored independently in `.kcad` files.


## restored.20 — поворот и масштаб объектов

Выделите объект и откройте вкладку «Свойства». В блоке «Масштаб объекта» задайте коэффициент (например, 1,5) или нажмите пресет ×0,5 / ×0,8 / ×1,25 / ×2. Для окружности, эллипса и прямоугольника можно также тянуть угловые маркеры рамки выделения. Shift при перетаскивании сохраняет пропорции.

Поворот задаётся абсолютным целевым углом в поле «Угол поворота», кнопкой «Повернуть», быстрыми шагами или янтарной ручкой над выделением.
