# КОМПАС Онлайн — браузерный редактор чертежей

Небольшой автономный учебный 2D-редактор технических чертежей. Проект работает локально в браузере и не требует установки библиотек, регистрации или подключения к интернету.

## Запуск

1. Распакуйте архив в отдельную папку.
2. Откройте `index.html` в Chrome, Edge или Firefox.
3. Начните чертить на листе. Для работы с текстом браузер покажет небольшое окно ввода.

## Что работает

- Листы A4 книжный, A4 альбомный и A3 альбомный.
- Встроенный векторный шаблон A4, восстановленный по предоставленному скриншоту: рамка, боковые регистрационные поля, верхнее поле и основная надпись.
- Редактирование полей основной надписи: наименование, обозначение, материал, масштаб, лист и организация.
- Инструменты: выбор и перемещение, отрезок, прямоугольник, окружность, текст и линейный размер.
- Слои геометрии, размеров/текста и шаблона; включение и выключение видимости.
- Цвет, толщина и тип линии для выбранного объекта.
- Сетка и привязка к шагу 5 мм.
- Масштабирование колёсиком и кнопками, перемещение рабочего поля средней кнопкой мыши или Space + перетаскивание.
- Отмена/повтор, удаление объектов, горячие клавиши.
- Сохранение и открытие собственного JSON-проекта.
- Экспорт в SVG и PNG, печать через браузер (в диалоге печати можно выбрать «Сохранить как PDF»).

## Горячие клавиши

- `Ctrl + S` — скачать проект JSON.
- `Ctrl + Z` — отменить.
- `Ctrl + Y` — повторить.
- `Delete` — удалить выбранный объект.
- `Esc` — сбросить построение и вернуться к выбору.
- `Space` + перетаскивание — перемещение рабочего поля.

## Файлы проекта

- `index.html` — окно приложения.
- `styles.css` — оформление интерфейса.
- `js/app.js` — логика редактора и инструментов.
- `js/template.js` — построение редактируемого векторного шаблона.
- `assets/template-a4-portrait.svg` — отдельная SVG-копия шаблона A4.
- `assets/original-template-reference.png` — исходный скриншот, предоставленный для ориентира.

## Ограничения текущей версии

Это самостоятельный учебный прототип 2D-черчения, а не полная копия КОМПАС-3D. Пока нет 3D-моделирования, параметрических зависимостей, полноценной поддержки ГОСТ/ДСТУ, открытия/сохранения CDW или DWG, автоматических видов/разрезов и расширенной системы допусков. SVG и PNG предназначены для обмена и просмотра; редактируемый формат проекта — JSON.
