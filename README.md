# CAD Geometry Core 1.5.58 — восстановленная сборка

Браузерный 2D-CAD для учебных технических чертежей в миллиметрах. В исходном ZIP остались интерфейс (`index.html`, `styles.css`) и документация, но отсутствовали все программные модули и тесты. Эта сборка восстанавливает рабочее ядро по сохранившимся интерфейсу, README, START_HERE и CHANGELOG.

## Публикация через GitHub Pages

1. Распакуйте архив на компьютере. В репозиторий нужно загрузить **содержимое** папки проекта, а не один ZIP-файл.
2. В корне репозитория должны лежать `index.html`, `styles.css`, папки `js/` и `src/`.
3. На GitHub откройте **Settings → Pages**. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните.
4. Откройте адрес Pages, показанный GitHub. Не переименовывайте и не переносите отдельно папки `js/` и `src/`: приложение загружает ES-модули по относительным путям.

Для локального запуска на Windows:

**Windows:** распакуйте папку целиком и дважды щёлкните `start.bat`. Скрипт поднимает локальный сервер и открывает редактор в браузере. Для этого нужен Node.js 18+ или Python 3.

**Вручную:** из папки проекта выполните:

```bash
npm start
```

Затем откройте `http://127.0.0.1:8000/`. Не запускайте `index.html` двойным щелчком: браузеры блокируют ES-модули при загрузке через `file://`.


## Навигация мышью

- Панорамирование двигает ВЕСЬ лист (белую бумагу вместе с рамкой и чертежом) по свободному серому рабочему пространству. Средняя кнопка/нажатие на колесико + движение или правая кнопка + движение панорамируют лист. На ноутбуке используйте Space + перетаскивание ЛКМ или включите кнопку «Ладонь» и тяните лист ЛКМ. Двухпальцевое плавное движение по тачпаду перемещает лист; горизонтальное движение тоже панорамирует. Колесико обычной мыши приближает/отдаляет ВИД относительно курсора; Ctrl+колесико и жест pinch на тачпаде также масштабируют. Кнопки «−» и «+» меняют только масштаб камеры. Ни один из этих жестов не изменяет рамку или геометрию внутри бумаги. Shift+колесо сдвигает по горизонтали, Alt+колесо — по вертикали.

## Восстановленные функции

- Листы A4, A3, A2, A1, A0 и ряд удлинённых форматов; книжная и альбомная ориентация.
- Тринадцать пресетов рамок: по умолчанию открывается чёрный образец ЛР №8 «Корпус / Вариант 8 / ШЦМГУ» на А3 альбомном 420×297 мм; доступны учебные ЛР4/ЛР5 и варианты формы 1 на листах А4/А3/А2. Рамка чертежа для образца расположена в 20 мм от левого и 5 мм от остальных краёв; основная надпись 185×55 мм находится внизу справа. Формат листа подстраивается под выбранный шаблон.
- Базовая геометрия: отрезки, стрелка с одним заполненным наконечником, окружности, прямоугольники, скруглённые прямоугольники, эллипсы, многоугольники, ломаные, дуги, свободные линии.
- Надписи, выноски, простые линейные/горизонтальные/вертикальные/радиальные/диаметральные размеры, центровые метки, осевые и вспомогательные линии, линейка, таблица.
- Выбор, множественный выбор, перемещение, удаление, дублирование, вращение, зеркальное отражение, масштабирование, массивы, выравнивание, свойства объектов.
- Сетка, привязка к сетке, базовые OSNAP к концам/серединам/центрам/квадрантам, Ortho и Shift-фиксация угла. Двухточечные инструменты работают как щелчками по двум точкам, так и протягиванием ЛКМ; ломаная и сплайн строятся последовательными щелчками.
- Локальное автосохранение, список файлов, `.kcad` (JSON-проект), экспорт SVG/PNG/JPEG/WebP и базовый DXF-импорт/экспорт.
- Печать через браузер / сохранение в PDF.

## Важные ограничения

Это восстановление, а не побитное возвращение исходного CAD-ядра: исходные `src/`, `js/`, `tests/`, `templates/` и `docs/` из архива отсутствовали. Сложные операции, описанные в старом README/CHANGELOG, не все восстановлены:

- проходные вырезы по замкнутым профилям «снаружи внутрь» / «изнутри наружу», булевы операции, режимы стенок и вырезание вложенных отверстий;
- произвольные Offset, Trim, Fillet, Chamfer, разделение замкнутых контуров и редактирование граней;
- автоматическое обнаружение нескольких вложенных областей для штриховки;
- полный DXF/DWG/CDW, CSV/HPGL/PLT, сложные DXF/SVG-сущности;
- параметрические зависимости и 3D-моделирование.

Эти пункты не маскируются: ограниченные кнопки сообщают об этом в строке состояния. DXF поддерживает базовые сущности, но экспорт нужно проверить в целевом CAD-приложении. Проверка ЕСКД — только учебный предварительный контроль, не официальный сертификат соответствия.

Точные ограничения и состав проверок: [`docs/RESTORATION-NOTES.md`](docs/RESTORATION-NOTES.md). Справка по категориям инструментов: [`docs/TOOL-TABS.md`](docs/TOOL-TABS.md).

## Статус стандартов для шаблона

Образец ЛР №8 реконструирован по предоставленному изображению в альбомном А3 (420 × 297 мм): рамка 20 мм слева и 5 мм с остальных сторон, нижний правый штамп 185 × 55 мм. Сетка штампа следует структуре формы 1; чёрные боковые поля и их подписи — индивидуальная часть образца, а не обязательный реквизит ГОСТ. В Украине ДСТУ EN ISO 5457:2022 указан как действующий стандарт форматов чертежных листов. ДСТУ ГОСТ 2.104:2006 в реестре отмечен как действующий с 01.03.2026 по 25.11.2027 с ограниченной сферой применения. Поэтому шаблон следует считать учебной реконструкцией по образцу, а не официальным сертификатом соответствия для любой области применения.

## Импорт проекта Kompas Online (.kcad)

В `examples/ЛР5-Кушвид-исходный-проект-Kompas-Online.kcad` приложен исходный файл, который был предоставлен для настройки рамки. Для импорта в редакторе нажмите **Импорт проекта** и выберите `.kcad`. Импорт создаёт отдельный проект и переносит распознанные объекты, размеры, текст, формат листа и поля основной надписи. Для этого файла распознаётся А4, книжная ориентация, и применяется восстановленный чёрный шаблон `kompas-lab5-a4-template`. Исходный файл не перезаписывается.

Поддерживаются типы объектов Kompas Online, присутствующие в предоставленном файле: отрезки, вспомогательные линии, полилинии/контуры, эллипсы, размеры и текст. Другие специфические сущности Kompas могут быть пропущены. После импорта проверьте размеры и подписи перед печатью или сдачей.

**Цвет рамок:** все рамки, вспомогательные поля и основная надпись в каталоге шаблонов строятся чёрным цветом. Цветовые маркеры в интерфейсе обозначают слои/инструменты и не меняют цвет печатной рамки.
