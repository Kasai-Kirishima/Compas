# CAD Geometry Core 1.1.0 — полный проект

Геометрическое ядро 2D САПР на JavaScript ES Modules для приложений на HTML5 Canvas. В архив включены исходный модуль, тесты, интерактивный пример, документация и настройки проекта.

## Состав проекта

```text
CAD-Geometry-Core-1.1.0/
├── src/
│   └── cad-geometry-trim.mjs      # Геометрическое ядро
├── tests/
│   └── test-cad-geometry.mjs      # Автоматические тесты
├── examples/
│   └── demo.html                  # Интерактивная Canvas-демонстрация Trim
├── package.json                  # Настройки и команды проекта
├── README.md                     # Инструкция и API
├── CHANGELOG.md                  # История версий
└── .gitignore                    # Исключения для разработки
```

Архив содержит все файлы, необходимые для работы с исходным кодом, запуска тестов и демонстрации. Временные скриншоты, логи, кэш, старые сборки и `node_modules` исключены. Внешние npm-зависимости для ядра не нужны.

## Требования

- Node.js 18+ для тестов.
- Современный браузер для Canvas-демонстрации.

## Быстрый запуск

Из корневой папки после распаковки:

```bash
npm run check
npm test
```

Чтобы открыть интерактивную демонстрацию, запустите локальный сервер из корневой папки, например:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000/examples/demo.html`. ES-модули не рекомендуется открывать через `file://`.

## Быстрое подключение

```js
import {
  Line, Centerline, Circle, Arc, Polygon,
  LinearDimension, DiameterDimension,
  trimAtPoint, applyEditTransaction,
  polarArray, serializeScene, deserializeScene
} from './src/cad-geometry-trim.mjs';

const line = new Line({ x: 0, y: 0 }, { x: 100, y: 0 });
const circle = new Circle({ x: 50, y: 40 }, 20);
const hexagon = Polygon.regular({ x: 140, y: 40 }, 6, 20);

// Круговой массив: шесть положений, включая оригинал.
const copies = polarArray([hexagon], { x: 140, y: 40 }, 6);

// Trim возвращает транзакцию, не меняя сцену автоматически.
const cutterA = new Line({ x: 30, y: -10 }, { x: 30, y: 10 });
const cutterB = new Line({ x: 70, y: -10 }, { x: 70, y: 10 });
const scene = [line, cutterA, cutterB, circle];
const edit = trimAtPoint(line, { x: 50, y: 0 }, scene, { hitTolerance: 2 });
if (edit.ok) {
  const updatedScene = applyEditTransaction(scene, edit);
  console.log(updatedScene);
}

// JSON-сохранение и восстановление.
const saved = JSON.stringify(serializeScene(scene));
const restored = deserializeScene(JSON.parse(saved));
```

## Координаты и единицы

Ядро работает в **мировых координатах**. Для машиностроительного чертежа удобно хранить координаты в миллиметрах. Ось Y рекомендуется направить вверх. При отрисовке в Canvas используйте преобразование:

```js
ctx.setTransform(scale, 0, 0, -scale, offsetX, offsetY);
```

`scale` — количество экранных пикселей на миллиметр; `offsetX` и `offsetY` задают экранное положение мирового начала координат. Для чтения размерных чисел при таком Y-up преобразовании функции `drawLinearDimension()` и `drawDiameterDimension()` дополнительно компенсируют вертикальное отражение текста.

## Геометрические классы

### Примитивы

```js
import {
  Line, Centerline, Circle, Arc, Polygon,
  LinearDimension, DiameterDimension
} from './src/cad-geometry-trim.mjs';

const line = new Line({x: 10, y: 10}, {x: 80, y: 10});
const axis = new Centerline({x: 40, y: 0}, {x: 40, y: 40});
const circle = new Circle({x: 50, y: 50}, 15);
const arc = new Arc({x: 50, y: 50}, 15, 0, Math.PI / 2); // start + signed sweep
const hex = Polygon.regular({x: 110, y: 50}, 6, 20);
const linear = new LinearDimension({x: 10, y: 10}, {x: 80, y: 10}, 8);
const diameter = new DiameterDimension({x: 50, y: 50}, 15, {angle: Math.PI / 4});
```

- `Line(a, b)` — конечный отрезок. Нулевые отрезки отклоняются при создании.
- `Centerline(a, b)` — отрезок со стандартным штрихпунктирным стилем.
- `Circle(center, radius)` — окружность.
- `Arc(center, radius, startAngle, sweep)` — дуга. `sweep > 0` задаёт направление против часовой стрелки, `sweep < 0` — по часовой; полный оборот допускается.
- `Polygon(vertices)` — замкнутый контур. Соседние повторяющиеся вершины и повтор последней вершины в начале очищаются; если остаётся менее трёх вершин, создаётся ошибка.
- `Polygon.regular(center, vertexCount, circumradius, rotation)` — правильный многоугольник по центру, числу вершин и радиусу описанной окружности.
- `LinearDimension(p1, p2, offset, options)` — линейный размер.
- `DiameterDimension(center, radius, options)` — диаметральный размер с префиксом `Ø`.

У каждого объекта есть `id`, `type`, `style`, `locked`, `visible`. Заблокированные объекты могут быть режущими границами Trim, но сами не редактируются.

## Пересечения

Реализованы следующие пары:

| Пара объектов | Метод |
|---|---|
| Отрезок — отрезок | Векторное произведение и параметры `t`, `u` |
| Отрезок — окружность | Проекция на прямую и расстояние до центра |
| Отрезок — дуга | Пересечение с окружностью плюс фильтр углового диапазона |
| Окружность — окружность | Расстояние центров и построение общей хорды |
| Окружность/дуга — дуга | Пересечение окружностей с угловой фильтрацией каждой дуги |

`intersectLineLine(a, b)` возвращает точки пересечения с параметрами вдоль обоих отрезков. Для коллинеарных отрезков возвращаются конечные точки области перекрытия (одна точка при касании концами, две при перекрытии диапазонов). Совпадающие окружности и совпадающие дуги не имеют конечного набора уникальных точек — для них возвращается пустой список, а не выдуманные точки.

`intersectLineCircle(line, circleOrArc)` возвращает точки только на конечном отрезке. Для дуги дополнительно применяется фильтрация по `startAngle` и `sweep`. Касание даёт одну точку, а не две почти одинаковые.

`intersectCircleCircle(a, b)` учитывает касание, внешнее/внутреннее непересечение, концентрические и совпадающие окружности.

`intersectionsOn(subject, objects)` собирает, сортирует и удаляет повторяющиеся пересечения вдоль выбранного объекта. Для отрезка параметр `t` находится на диапазоне `[0, 1]`; для окружности нормализованный параметр равен `angle / 2π`; для дуги `t` идёт от начала до конца её знакового углового размаха.

Для численной устойчивости используются одновременно абсолютный допуск пользователя и поправка на машинную точность координат. Это особенно важно для чертежей, расположенных далеко от мирового нуля.

## Trim / Усечь

`trimAtPoint(subject, clickPoint, objects, options)` **не меняет сцену сам**. Он возвращает атомарную транзакцию `{ ok, remove, add, removed }` или `{ ok: false, reason }`.

```js
import { hitTest, trimAtPoint, applyEditTransaction } from './src/cad-geometry-trim.mjs';

function onTrimClick(worldPoint, scene, tolerance = 2) {
  // Последний элемент массива — верхний объект в Z-порядке.
  const target = [...scene].reverse().find(object =>
    object.visible && !object.locked && hitTest(object, worldPoint, tolerance)
  );
  if (!target) return { scene, message: 'Не найден доступный объект' };

  const edit = trimAtPoint(target, worldPoint, scene, { hitTolerance: tolerance });
  if (!edit.ok) return { scene, message: edit.reason };
  return { scene: applyEditTransaction(scene, edit), message: 'Участок удалён' };
}
```

Алгоритм:

1. Проверяется выбранный объект, блокировка и расстояние от клика до его геометрии.
2. По всем видимым геометрическим объектам ищутся пересечения. Размерные аннотации не участвуют в качестве режущих границ.
3. Пересечения сортируются вдоль объекта, касательные точки дедуплицируются.
4. Для отрезка и дуги к списку границ добавляются их концы. Удаляется только соседний интервал, внутри которого находится проекция клика.
5. Для окружности выбирается циклический интервал между соседними пересечениями. Требуются минимум две разные точки пересечения.
6. Возвращается транзакция: отрезок/дуга разбивается на оставшиеся части, окружность преобразуется в оставшуюся дугу.

Многоугольник сначала преобразуется в редактируемые стороны через `explodePolygon(polygon)`. Его стороны получают `ownerId`; соседние стороны того же исходного контура не должны становиться режущими границами друг для друга.

Ограничения Trim: совпадающие окружности/дуги и бесконечная коллинеарная общая геометрия не трактуются как бесконечное множество точек. Для коллинеарных конечных отрезков ядро использует границы конечного перекрытия.

## Круговой массив

```js
import { polarArray } from './src/cad-geometry-trim.mjs';

// 6 равноотстоящих позиций по полному кругу, включая оригинал.
const sixPositions = polarArray([line, circle], {x: 0, y: 0}, 6);

// 3 новые копии между начальным и конечным углом; оригинал не включён.
const threeCopies = polarArray([line], {x: 0, y: 0}, 3, {
  totalAngle: Math.PI,
  includeOriginal: false
});
```

При `includeOriginal: true` `count` — общее количество позиций массива, вместе с исходными объектами. При `false` `count` — число новых копий, равномерно расположенных между исходным положением и конечным углом.

## Трансформации и привязки

- `rotatePrimitive(object, center, angle)` — поворот вокруг точки, включая линейные и диаметральные размеры.
- `translatePrimitive(object, delta)` — перемещение без мутации исходника.
- `scalePrimitive(object, factor, origin)` — равномерное масштабирование. Для радиусов и высот текста используется модуль коэффициента.
- `mirrorPrimitive(object, axisA, axisB)` — отражение относительно бесконечной оси; у дуги меняется знак `sweep`.
- `snapPoints(object)` — концы, середины, центры, квадранты и вершины в зависимости от типа геометрии.
- `intersectionSnapPoints(objects)` — точки попарных пересечений видимых геометрических объектов.
- `hitTest(object, point, tolerance)` — простой тест попадания курсора в геометрию.

Все трансформации возвращают новые экземпляры, исходные объекты не меняются. Созданные копии по умолчанию разблокированы — это ожидаемое поведение команды копирования.

## Размеры и чертёжный шрифт

`LinearDimension` и `DiameterDimension` хранят вычисляемое значение, ручной текст, флаг `showValue` и высоту надписи. `GOST_TEXT_HEIGHTS` содержит ряд высот чертёжного шрифта: 1,8; 2,5; 3,5; 5; 7; 10; 14; 20; 28; 40 мм. `assertGostTextHeight()` проверяет введённое значение.

`drawPrimitive(ctx, object)` рисует как обычные примитивы, так и размерные аннотации. `drawLinearDimension()` держит цифры горизонтальными при наклонной размерной линии, делает белую маску под надписью и автоматически выводит стрелки наружу, если для них недостаточно места. Для контекста с мировыми координатами Y вверх функция компенсирует переворот текста. Если приложение использует другую систему координат, настройку рендера следует адаптировать.

Наличие правильной высоты надписи само по себе не гарантирует полного соответствия ГОСТ 2.304: конкретная гарнитура должна быть совместимой с чертёжным шрифтом. CSS `sans-serif` — только резерв, если CAD-шрифт не установлен.

## Сохранение

```js
import { serializeScene, deserializeScene } from './src/cad-geometry-trim.mjs';

const json = JSON.stringify(serializeScene(scene));
const restoredScene = deserializeScene(JSON.parse(json));
```

Формат сцены версионируется полем `version`. Сериализуются геометрия, стили, блокировка, видимость и параметры размеров.
