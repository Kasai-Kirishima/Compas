# Архитектура CAD Geometry Core 1.6.0

## Точка входа
- `index.html` — интерфейс редактора и SVG-холст.
- `styles.css` — оформление интерфейса, холста и модальных окон.
- `js/template.js` — встроенные SVG-шаблоны A3/A4; шаблоны загружаются из памяти, поэтому запуск `file://` не требует `fetch()`.
- `js/app.js` — клиентский runtime: события интерфейса, SVG-отрисовка, состояние документа, инструменты, импорт/экспорт и печать.

## Геометрия и данные
- `src/geometry.mjs` — чистые геометрические вспомогательные функции в миллиметрах.
- `src/project-schema.mjs` — проверка и нормализация структуры `.kcad`.
- `tests/test-core.mjs` — быстрые проверки Node.js.

## Шаблоны и материалы
- `templates/Лаба_8/` — исходные редактируемые SVG-рамки A3 и A4.
- `assets/Лаба_8/preview/` — PNG-предпросмотры рамок.
- `assets/Лаба_8/reference/` — загруженный образец рамки, использованный при подготовке.
- `examples/` — пример редактируемого проекта.

## Форматы
- `.kcad` — JSON-документ редактора (геометрия, параметры листа, шаблон и штамп).
- SVG/PNG — графический экспорт листа.
- DXF/CSV — базовый обмен геометрией; поддержка DXF ограничена базовыми типами сущностей.

## Важное о происхождении
Полученный первоначальный ZIP содержал интерфейс и CSS, но папки `js/`, `src/` и `tests/` были пустыми, хотя HTML подключал скрипты, которых не было. Точный исходный движок восстановить из отсутствующих байтов невозможно. В этой версии написан новый базовый runtime, совместимый с сохранённой HTML/CSS-оболочкой. Это не побайтное восстановление прежней программы.
