# Клавиши и управление

| Действие | Управление |
|---|---|
| Сохранить проект `.kcad` | Ctrl+S |
| Отменить | Ctrl+Z |
| Повторить | Ctrl+Y |
| Завершить ломаную | Enter |
| Отменить текущий жест / вернуться к выбору | Esc |
| Ортогональный режим | F8 |
| Удалить выделенный объект | Delete / Backspace |
| Масштаб | Колесо мыши |

Для прямых и фигур: выберите инструмент, зажмите левую кнопку, протяните курсор и отпустите. Для ломаной ставьте вершины щелчками. Для текста щёлкните по пустому месту листа, введите надпись и нажмите «Применить текст». Изменение текста — выберите инструмент «Текст» и щёлкните по существующей надписи.

При печати/сохранении в PDF укажите размер бумаги, соответствующий текущему листу, масштаб 100% / Actual size и отключите автоматическое вписывание в страницу.
