KOMPAS ONLINE — PATCH 2.5.1 (targeted title-block readability fix)

This is a small correction to the restored v2.5 project. It does not replace
or redesign the overall Lab 5 sheet layout.

Changes:
- Corrected Form 1 content order: graph 2 (document designation) is above
graph 1 (document/product name).
- The upper-left additional designation field contains only the document code
and is rotated 180 degrees (graph 26).
- Removed the redundant literal label "Позначення:" from the code fields.
- Improved title-block text rendering and removed unnecessary skew from values.
- Developer and checker names are centered and wrapped to stay inside their cells.
- Added the organization and group in a two-line, readable organization field.
- Material is blank when not specified; the old placeholder "Матеріал не зазначено"
is treated as empty.
- For a one-sheet document, graph 7 (Аркуш) is left blank and graph 8 (Аркушів)
contains 1.
- The scale value is rendered only once.
- Literature mark У is placed in the first of the three literature sub-cells.
